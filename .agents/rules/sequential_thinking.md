# Sequential Thinking Guidelines

You must ALWAYS use the sequential thinking tool (`sequential-thinking` MCP server) whenever you reason through tasks, plan implementations, solve problems, or make decisions.

## Instructions:
1. For any user request, architectural plan, design decision, or debugging task, invoke the sequential thinking tool first.
2. Break down the problem step-by-step into structured thoughts.
3. Formulate hypotheses, verify edge cases, and reflect before taking critical actions.
4. Continue the sequential thinking process across thought steps until the solution path is completely clear.
